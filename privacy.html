Политика конфиденциальности

Последнее обновление: 26 апреля 2026 г.

Настоящая Политика конфиденциальности описывает, какие данные собираются при использовании приложения ОДИН·ДВА (сайт odin-dva.ru), как они используются и какие права есть у пользователя.

1. Что мы собираем

Приложение не собирает персональные данные напрямую — нет регистрации, нет аккаунтов, нет форм с личной информацией.

При посещении сайта автоматически собираются анонимные технические данные через сервисы аналитики:

Яндекс.Метрика (Яндекс ООО)
Собирает: IP-адрес (анонимизированный), браузер, операционная система, страницы посещения, время сессии, клики, поведение на странице (Вебвизор).
Хранение: до 24 месяцев.
Политика: yandex.ru/legal/confidential
Google Analytics 4 (Google LLC)
Собирает: IP-адрес (анонимизированный), браузер, устройство, страна, страницы посещения, источники трафика.
Хранение: до 14 месяцев.
Политика: policies.google.com/privacy

2. Данные на вашем устройстве

Все тренировки, настройки и история сохраняются исключительно на вашем устройстве и не передаются на серверы:

  • localStorage — тренировки, настройки, история сессий
  • IndexedDB — аудиофайлы музыки (если вы загружаете свою музыку)

Эти данные доступны только вам. При очистке данных браузера они удаляются безвозвратно.

3. Разрешения приложения

  • Web Audio API — воспроизведение звуков и музыки. Доступа к микрофону нет.
  • Wake Lock API — предотвращает блокировку экрана во время тренировки.
  • Vibration API — вибрация при смене фаз (только на мобильных устройствах).
  • Web Share API — поделиться тренировкой через системное меню устройства.

4. Cookies

Приложение не использует собственные cookies. Сервисы аналитики (Яндекс.Метрика, Google Analytics) устанавливают cookies для идентификации сессий.

Вы можете отключить cookies в настройках браузера или использовать расширения для блокировки трекеров (например, uBlock Origin).

5. Передача данных третьим лицам

Мы не продаём и не передаём ваши данные третьим лицам. Данные аналитики обрабатываются только Яндексом и Google в рамках их собственных политик конфиденциальности.

6. Несовершеннолетние

Приложение не предназначено для детей до 16 лет. Мы не собираем данные детей намеренно. Если вам стало известно о данных несовершеннолетнего — свяжитесь с нами.

7. Ваши права

  • Отказаться от аналитики: установить расширение-блокировщик или отключить cookies в браузере
  • Удалить свои данные с устройства: очистить данные сайта в настройках браузера
  • Запросить информацию: написать на контактный email

8. Изменения политики

При существенных изменениях политики дата обновления в заголовке будет изменена. Рекомендуем периодически проверять эту страницу.
