## Фаза 3 — Вирусный рост (май–июнь 2026)

### Deep Linking — поделиться тренировкой как ссылкой
Сейчас: Web Share API отдаёт JSON-файл (неудобно)  
Цель: `https://odin-dva.ru/?workout=BASE64_DATA`

- [ ] Кодировать тренировку в base64 и вставлять в URL
- [ ] При открытии ссылки — парсить параметр и предлагать импорт
- [ ] Кнопка "Поделиться ссылкой" рядом с текущей "Поделиться файлом"

Реализация (только фронтенд, не нужен сервер):
```javascript
const encoded = btoa(unescape(encodeURIComponent(JSON.stringify(workout))));
const url = `https://odin-dva.ru/?w=${encoded}`;
navigator.share({ url, title: workout.name });
```

## Фаза 4 — Регистрация и облако (июль–сентябрь 2026)

### Выбор стека для бэкенда
**Рекомендация: Supabase** (не Django)

| | Supabase | Firebase | Django |
|---|---|---|---|
| Сложность | Низкая | Низкая | Высокая |
| БД | PostgreSQL | NoSQL | PostgreSQL |
| Auth | Есть | Есть | Нужно писать |
| JS SDK | Да | Да | REST API |
| Бесплатный tier | 500 MB, 50k req/мес | 1 GB, 50k req/мес | Нет |
| Деплой | Hosted | Hosted | Нужен сервер |
| **Вывод** | ✅ Лучший выбор | Альтернатива | Нет |

### Что реализовать
- [ ] Регистрация / вход: Google OAuth + Email
- [ ] Синхронизация тренировок через Supabase DB
- [ ] Привязка истории тренировок к аккаунту
- [ ] Облачное хранение музыки (Supabase Storage)
- [ ] Реферальная система: `?ref=USER_ID` → бонусы

### Архитектура (Supabase)
```
PWA (localStorage) 
    ↕ sync при логине
Supabase (PostgreSQL)
    - users
    - workouts
    - history
    - music_files (Storage bucket)
```
