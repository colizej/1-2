# ОДИН·ДВА — план улучшений

## ✅ Реализовано

- **Wake Lock API** — экран не гаснет во время тренировки
- **Экспорт / Импорт** — экспорт конкретной тренировки из gear sheet, импорт через кнопку +
- **Время отдыха в деталях** — видно рядом с каждым упражнением
- **Суммарное время на карточке** — реальный итог вместо дефолтного w.work
- **Реструктуризация файлов** — static/, icons/ чисто разложено
- **Прогресс-карточки** — горизонтальный свайп, 1 карточка = 1 тренировка (агрегация), детальный экран с таблицей сессий
- **SVG иконки** — заменены emoji на векторные stroke-иконки, градиентный фон
- **SEO** — `meta description`, `robots.txt` (Allow / Disallow), `sitemap.xml`, тэглайн-гравировка
- **Удалён .DS_Store** из репо, добавлен в `.gitignore`
- **Google Analytics 4** — подключён трекинг `G-1D6J41RLMG`
- **Google Search Console** — верификация, sitemap отправлен
- **Прогресс — activity log** — вертикальный список вместо карточек (дата слева, название+статистика справа)
- **Статистика в шапке прогресса** — общее кол-во сессий и суммарное время
- **Баннер установки PWA** — `beforeinstallprompt`, хранит флаг отказа в localStorage
- **Чистка orphaned блобов** — сканирование IndexedDB при старте, удаление потерянных треков
- **Drag & drop упражнений на экране детали** — `makeSortable()` утилита (Touch+Mouse), порядок сохраняется в localStorage. Работает Chrome + Safari iOS.
- **Общее время тренировки на экране детали** — строка «Итого X мин» под списком упражнений.
- **Дублировать тренировку** — кнопка в gear sheet, создаёт копию «Дубликат — Название».
- **Поделиться тренировкой** — Web Share API (JSON-файл), fallback на скачивание. Кнопка скрыта если API недоступен.
- **Open Graph / Twitter Card** — `og:title`, `og:description`, `og:image` (1200×630), `twitter:card summary_large_image`, `canonical`. Красивые превью в мессенджерах.
- **OG-образ и иконки** — `icons/og-image.svg` (тёмный фон, логотип, «ОДИН·ДВА», «Interval Timer», «odin-dva.ru»), PNG генерируется через `make og` (`scripts/gen-og.js`). Все иконки (512/192/180/32) перегенерированы из правильного `favicon.svg`.
- **Имя JSON при шаринге** — формат `odin-dva-NAME-DATE.json`. Текст шаринга содержит название тренировки и ссылку `https://odin-dva.ru`.
- **Тост-уведомления** — `showToast(msg)` появляется при добавлении упражнения, сохранении, удалении и дублировании тренировки.
- **Авто-прокрутка к новому упражнению** — `scrollIntoView` при добавлении упражнения в форму.
- **Отключение музыки по фазам** — кнопка-переключатель рядом с каждой фазой (Работа / Отдых / Финиш); состояние сохраняется в тренировке (`musicMutedWork/Rest/Fin`).

- **App Store / Google Play** — публикация через PWABuilder. Для ASBL: нужен D-U-N-S номер (~5 дней), Apple Developer $99/год, аккаунт как Organization.

- **Плейлист треков** — несколько треков на фазу (требует сервер или S3, ~50+ MB)

## 🔮 Будущее (требует сервер / БД)

### Плейлист треков по фазам
Сейчас: 1 трек на фазу (Работа / Отдых / Финиш).
Цель: несколько треков на фазу — воспроизводятся по очереди, не зацикливаясь.
UX: список треков с крестиком для удаления, кнопка «+ Добавить трек».
Нужна БД/сервер: один аудиофайл ~5–10 MB, плейлист из 5–10 треков = 50–100 MB+ → IndexedDB ненадёжен в таких объёмах.

### Цикл тренировок (плейлист тренировок)
Последовательный автозапуск нескольких тренировок подряд.
Актуально когда у каждой части тренировки своя музыка (разминка / HIIT / заминка).
Пока заменяется одной большой тренировкой — откладываем.
