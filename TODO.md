# ОДИН·ДВА — план улучшений

## ✅ Реализовано

- **Wake Lock API** — экран не гаснет во время тренировки
- **Экспорт / Импорт** — экспорт конкретной тренировки из gear sheet, импорт через кнопку +
- **Время отдыха в деталях** — видно рядом с каждым упражнением
- **Суммарное время на карточке** — реальный итог вместо дефолтного w.work
- **Реструктуризация файлов** — static/, icons/ чисто разложено

## 🟡 Следующие фичи

### 1. Перетаскивание упражнений (drag & drop)
Сейчас для смены порядка нужно удалить и добавить заново.
Решение: нативный HTML5 drag или SortableJS (~10 KB).

### 2. Общее время тренировки на экране детали
Показывать под списком упражнений: «Итого ~12 мин».
Считать: prepTime + сумма `(exercise.duration + exercise.rest)` по всем.

### 3. Дублировать тренировку
Кнопка «Дублировать» в gear sheet.
Копирует workout с новым id и названием «Копия — Название».
Музыкальные блобы тоже копировать через IndexedDB.

### 4. Поделиться тренировкой
Web Share API (`navigator.share({ files: [jsonBlob] })`) — нативный шаринг на iOS/Android.

## 🟢 Мелкие улучшения

### 5. Редизайн карточек Прогресса
Сделать компактнее — не дублировать стиль карточек тренировок.
Идея: левая часть — дата (число + месяц крупно, день недели мелко), правая — название + время.
Стиль activity log (GitHub, Strava).

### 6. Сводная статистика в прогрессе
Над историей: `Всего тренировок: 24 · Общее время: 4 ч 12 мин`.

### 7. Баннер «Установить приложение»
Слушать `beforeinstallprompt`, показывать тонкий баннер при первом заходе.
Хранить флаг в localStorage.

### 8. Проверить утечку музыкальных блобов
При редактировании с заменой музыки старый блоб в IndexedDB не удаляется.
В `openEditScreen` запомнить старые ключи → при `saveWorkout` удалить orphaned блобы.
