# ОДИН·ДВА — план улучшений

## 🔴 Критично для юзабилити

### 1. Wake Lock API
Экран гаснет во время тренировки, пока телефон лежит на полу.
```js
// startWorkout() — запрос блокировки
let wakeLock = null;
async function requestWakeLock() {
  try { wakeLock = await navigator.wakeLock.request('screen'); } catch {}
}
// finishWorkout() / btn-stop-timer — освобождение
function releaseWakeLock() {
  if (wakeLock) { wakeLock.release(); wakeLock = null; }
}
// visibilitychange — повторный запрос при возврате в приложение
document.addEventListener('visibilitychange', () => {
  if (document.visibilityState === 'visible' && timer.running) requestWakeLock();
});
```

## 🟡 Полезные фичи

### 3. Общее время тренировки на экране детали
Показывать под списком: «Итого ~12 мин».
Считать: сумма `(exercise.duration + exercise.rest)` по всем упражнениям + prepTime.

### 4. Дублировать тренировку
Кнопка «Дублировать» в gear sheet рядом с Редактировать.
Копирует workout с новым id и названием «Копия — Утренняя планка».
Музыкальные блобы тоже копируются через IndexedDB.

### 5. Поделиться тренировкой (Share / QR)
Закодировать workout JSON в Base64 → вшить в URL или сгенерировать QR-код.
Получатель открывает ссылку — приложение импортирует тренировку автоматически.
Либо: Web Share API (`navigator.share({ files: [jsonBlob] })`) — нативный шаринг на iOS/Android.

## 🟢 Мелкие улучшения

### 6. Баннер «Установить приложение»
Слушать событие `beforeinstallprompt`, показывать тонкий баннер при первом заходе.
Хранить `odindva_install_dismissed` в localStorage чтобы не показывать повторно.

### 7. Сводная статистика в прогрессе
Над карточками истории добавить строку:
`Всего тренировок: 24 · Общее время: 4 ч 12 мин`
Считается из `odindva_history` при каждом рендере.

### 9. Редизайн карточек Прогресса
Сейчас карточки истории похожи на карточки тренировок — слишком громоздко.
Сделать компактнее: горизонтальная строка вместо карточки, или плотная сетка квадратных тайлов.
Идея: левая часть — дата (число + месяц крупно, день недели мелко), правая — название тренировки + время.
Без теней, минимальные отступы, шрифт меньше. Смотреть на стиль activity log (GitHub, Strava).

### 8. Проверить утечку музыкальных блобов
При редактировании workout с заменой музыки старый блоб в IndexedDB не удаляется.
Нужно в `openEditScreen` запомнить старые ключи и при `saveWorkout` удалить orphaned блобы.
