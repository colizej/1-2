# ОДИН·ДВА — Interval Timer PWA

Прогрессивное веб-приложение для интервальных тренировок. Работает офлайн, устанавливается на главный экран телефона.

## Возможности

- **Тренировки с подходами** — название, иконка, список подходов с индивидуальным временем Работы и Отдыха для каждого
- **Настройка подготовки** — настраиваемый обратный отсчёт перед первым подходом (3–30 сек)
- **Таймер с визуализацией** — круговой прогресс-бар, подсветка фаз, обратный отсчёт 3-2-1
- **Музыка по фазам** — отдельный трек для фазы «Работа» и «Отдых»; хранится локально через IndexedDB
- **Звуковые сигналы** — Web Audio API, sample-accurate воспроизведение через AudioBuffer
- **Прогресс** — история тренировок с возможностью удаления записей
- **Адаптивный дизайн** — mobile-first, на десктопе ограничена шириной 480 px
- **PWA** — офлайн через Service Worker, иконки 192/512/180 px, fullscreen

## Стек

| Слой | Технологии |
|------|-----------|
| UI | Vanilla HTML / CSS (Custom Properties, Flexbox, CSS Animations) |
| Логика | Vanilla JavaScript (ES2020+) |
| Хранилище тренировок | `localStorage` |
| Хранилище музыки | `IndexedDB` (база `odindva_music`) |
| Звук | `Web Audio API` (AudioContext + AudioBuffer) |
| Офлайн | `Service Worker` (cache-first) |
| Манифест | `manifest.json` (fullscreen, portrait) |

## Запуск локально

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Флоу тренировки

```
Подготовка (N сек) → [Работа → Отдых] × подходы → 🎉 Результат
```

- Отдых = 0 у подхода → фаза отдыха пропускается
- После последнего подхода — сразу экран результатов

## Экраны

1. **Главная** — список тренировок + история с прогрессом
2. **Детали** — подходы тренировки, кнопка «Старт», меню редактирования/удаления
3. **Создание/редактирование** — форма: название, подходы (Работа + Отдых у каждого), время Подготовки, музыка
4. **Таймер** — анимированный круговой таймер, пауза по тапу, индикатор подходов
5. **Результаты** — конфетти, статистика сессии, лог по упражнениям

## Хранение данных

| Данные | Где |
|--------|-----|
| Тренировки | `localStorage` ключ `odindva_workouts` |
| История | `localStorage` ключ `odindva_history` |
| Музыкальные треки | `IndexedDB` база `odindva_music` |

Все удаления требуют подтверждения через встроенный диалог.
